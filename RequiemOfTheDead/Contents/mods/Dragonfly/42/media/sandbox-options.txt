/* ONE PAGE, SECTIONS BY DECOY - the suite convention, converged 2026-08-22.
   The *Header booleans below are inert dividers, false by default and read by
   nothing. They exist because the settings screen has no sub-categories:
   CustomSandboxOption carries exactly id/page/translation and a page is
   created the first time an option names it (ServerSettingsScreen.lua:
   5133-5147), so a decoy option is the only sectioning it can express.
   Section order is declaration order. Dragonfly's admin panel renders these
   as dividers; the vanilla screen shows checkboxes that do nothing.
   Page names are presentational - no option id or SandboxVars accessor moved.
*/
