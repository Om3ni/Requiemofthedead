/* PAGE ORDER IS THE ORDER OF THE BLOCKS BELOW. Verified in 42.20: the server
   settings screen walks every option and creates a page the first time it sees
   one naming it (ServerSettingsScreen.lua:5133-5147), appending to the end - so
   first-encounter order is the only layout control that exists. There are no
   sub-categories: CustomSandboxOption carries exactly id/page/translation and
   the parser rejects any block that is not "option". Group modules by naming
   the page "Odds & Ends: X" so they read as one family in a screen shared with
   every other mod on the server.
*/

/* ============================================================
   Action Speed - per-family timed-action scaling. A world rule,
   not an admin tool: moved out of Dragonfly 2026-07-30, where it
   had landed only because Dragonfly owned a sandbox page.

   THE DEFAULTS BELOW ARE NOT "VANILLA" AND THAT IS DELIBERATE.
   The move renamed RFTDDragonfly.AS* -> RFTDOddsAndEnds.AS*, so
   on the first boot after it the server has no stored value for
   any of these and writes the declared default. These defaults
   are therefore set to the RotD server's live tuning as of
   2026-07-30, which makes the namespace change invisible in play
   instead of silently reverting seven dials to vanilla.

   Read that twice before changing them: a default here only ever
   applies to a world that has never seen the option. Once the
   server writes its sandbox config the stored value wins and
   these numbers stop mattering - so this trick works exactly
   once, on the boot that follows the rename.

   If a future season wants a genuinely neutral out-of-the-box
   posture, set them all back to 1 (Vanilla) THEN - by which
   point every existing world has its own stored values and
   nothing moves underfoot.

   THE SCALE IS 8 RUNGS, RENUMBERED 2026-07-30:
     1 Vanilla   2 = 2x   3 = 5x   4 = 10x
     5 = 20x     6 = 30x  7 = 40x  8 = Instant
   The 2x and 5x rungs are new; before them the dial jumped from
   vanilla straight to 10x. Adding them shifted every value above
   1, so the defaults above are the SAME SPEEDS as the server was
   running, written in the new numbering (reading/hood 20x = 5,
   the four 10x families = 4). Renumbering was free only because
   nothing had been stored yet. It will not be free again - and
   VALUE_DIV in ASScale.lua, numValues here, and the
   OE_ASpeed_option* labels must move together or the dial will
   promise one speed and deliver another.
   ============================================================ */

    default = true,

    translation = OE_ActionSpeedEnable,

/* ============================================================
   Noise Ordinance - horns and sirens still sound, but stop herding.

   A world rule rather than a taste one, which is why it defaults
   ON here: leaning on the horn to drag a crowd off a street is
   the exploit, and the noise is not. Sirens use the engine's own
   SirenEffectsZombies gate; their sound and lights are separate.
   Turning this OFF restores the horn and the native siren policy
   that was in force before Noise Ordinance took ownership.

   Renamed from QuietHornEnable on 2026-08-15 by owner decision.
   There is deliberately no compatibility alias: the new option
   is visible as Noise Ordinance and receives its declared default.
   ============================================================ */

option RFTDOddsAndEnds.NoiseOrdinanceEnable
{
    type = boolean,
    default = true,
    page = OE_NoiseOrdinance,
    translation = OE_NoiseOrdinanceEnable,
}

/* ============================================================
   Container Order - drag the container buttons in your own
   inventory sidebar into the order you want.

   Moved out of RFTDCore 2026-07-31. It is the only module here
   whose kill switch exists for COMPATIBILITY rather than taste:
   third-party container mods (Better Containers, Clean UI and
   friends) reorder the same button column, and while COClient is
   dormant until the player drags something, a player who wants
   both should be able to say which one wins. Turn this off on a
   server that ships one of those in its collection.
   ============================================================ */

    page = OE_ContainerOrder,
    translation = OE_ContainerOrderEnable,
