Limes Zone Converter

Offline, one-way: a PhunZones v2 export (the PhunZones.txt Lua table) in, a Limes schema-1 JSON document out. Nothing leaves this page; nothing is executed — the file is parsed by grammar, never evaluated. Nothing is silently lost: difficulty archetypes become tier records carrying their production dials, rect-less behavior templates become profiles (zones that inherited them now apply them), _default survives as the defaults record, and lewtkey values become profile stubs to fill in the Profiles panel. Only the sprinter min/max bands are dropped — superseded by tier sprinter rules — and every drop is reported. Import the result through the Zones tab's Import, which accepts only this schema.
